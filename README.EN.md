# 📄 Personal Resume — Demo

Static multilingual web resume generated as a **demo page** for the main project [CV para Todos](https://github.com/RaulMartinGuerrero/CV-para-todos).

This repository contains the exported static version of a CV built with the **techy** template from the generator. It is designed to serve as a live example of what any user can create with the main project.

---

🌐 **[View Live Demo](https://rmartinguerrero.github.io/personal-resume/)**

---

## ✨ Features

* 🌍 **Native Multilingual:** Supports Spanish, English, and Italian with automatic browser language detection.
* 🎨 **Techy Template:** Dark technical design with JetBrains Mono and Inter typography.
* ⚡ **Optimal Performance:** Static HTML/CSS/JS page with no backend dependencies or heavy frameworks.
* 📱 **Fully Responsive:** Adapts to any screen size.
* 🔒 **Privacy:** No cookies, no trackers, no telemetry.

---

## 📁 Project Structure

```
├── index.html            # Entry page (automatic language redirect)
├── style.css             # Unified styles with 3 themes (minimalist, techy, artistic)
├── profile.webp          # Profile photo
├── resume.es.json        # CV data in Spanish (JSON Resume standard)
├── resume.en.json        # CV data in English
├── resume.it.json        # CV data in Italian
├── es/index.html         # CV rendered in Spanish
├── en/index.html         # CV rendered in English
├── it/index.html         # CV rendered in Italian
└── .nojekyll             # Prevents Jekyll processing on GitHub Pages
```

---

## 🚀 Deployment

The site is deployed on **GitHub Pages** and updates automatically on push to the repository.

### Local Development

To preview the demo locally, simply open `index.html` in a browser or use a local server:

```bash
# With Python
python -m http.server 8000

# With Node.js
npx serve .
```
